# 企画の正本（design.md）

> オーナーが更新する。AIは直接書き換えず、Issueで提案する。
> 状態：`確定` / `案` / `未決`

## 1. コンセプト
- Terraria風の2D採掘・クラフト　`確定`
- 実在の鉱物を採掘 → 精錬で金属を取り出す → 配合比を変えて自作合金を作る　`確定`
- 装備パーツ：合金（刃・頭）＋ 木の交配で育てた柄 ＋ 魔力を込めた宝石　`確定`

## 2. 鉱物の差別化方針
- 精錬後の主金属は共通（赤鉄鉱からも磁鉄鉱からも同じ「鉄」）　`確定`
- 個性は **副産物・工程・探し方** に持たせる　`案`
- 副産物を共通レシピの「添加材」として効かせる（主金属は共通、添加材が特性を決める）　`案`
- 専用レシピは象徴的なものだけ数個　`案`
- 主金属は由来を問わず1スタックに統合し、副産物だけ別スタックにする　`案`

### 避けたいこと（他ゲームからの教訓）
- 微差の数値だけで横並びにすると実質リスキンになる（Terrariaの銅/錫）
- 産出量に見合う消費先がないとゴミ鉱石扱いになる（Minecraftの銅）
- 配合比が単純な足し算だと最適解が1つに収束する → トレードオフと状況依存を入れる

## 3. 鉱物候補（試案）
`【現】` 現実の性質　/　`【ゲ】` ゲーム独自の効果

| 鉱物 | 主金属 | 【現】 | 【ゲ】案 | 欲しくなる場面 |
|---|---|---|---|---|
| 赤鉄鉱 | 鉄 | 条痕が赤い、赤オーカー、研磨剤（ジュエラーズルージュ） | 副産物：研磨粉 → 宝石の品質アップ。チョークは低ランク用途 | 良い原石を拾った直後 |
| 磁鉄鉱 | 鉄 | Fe約72%、磁性、チタン磁鉄鉱はバナジウム源 | 歩留まり◎、磁性粉（合金に引き寄せ特性）、まれにV | 新バイオーム前、V鋼を作りたいとき |
| 褐鉄鉱（沼鉄鉱） | 鉄 | 沼で再生、リンが多く脆い鉄になりやすい | 沼でリスポーン、低歩留まり | 序盤、掘り尽くしたあと |
| 菱鉄鉱 | 鉄 | 炭酸塩で焙焼が必要、Mnを含み製鋼向き | 焙焼の手間、副産物Mn（鋼の添加材） | 鋼に進むタイミング |
| 黄鉄鉱 | （鉄にならない） | 打つと火花、硫黄が多い | 着火具・硫黄、まれに金 | 松明・爆薬が切れたとき |
| 孔雀石 | 銅 | 還元しやすく最初期の銅鉱候補、緑顔料 | 低ランク炉でOK、緑染料 | 序盤 |
| 黄銅鉱 | 銅 | 主要鉱石だがCu約35%、脱硫が必要 | 量は多いが設備が要る、硫黄・鉄が副産 | 量産したいとき |
| 自然銅 | 銅 | 精錬せず叩いて加工できる | 炉なしで使える、少量 | 出先で道具が壊れたとき |
| 錫石 | 錫 | 比重約7、川の砂錫 | 川底をふるいで採取、青銅の鍵 | 青銅を作りたいとき |
| 方鉛鉱 | 鉛 | 含銀方鉛鉱は銀の主要源 | 鉛＋銀（宝石の台座） | 魔力装備を作るとき |
| 蛍石 | — | 製錬の融剤、名前の由来も「流れる」 | 精錬の歩留まり・品質アップの消耗品 | 大量精錬の前 |

### 20〜30種に増やすときの候補メモ
- 閃亜鉛鉱（Cd・In・Ge・Ga副産）、辰砂（朱・水銀・毒性）、輝安鉱（低融点）、硫砒鉄鉱（ニンニク臭・金の担い手）、灰重石（UVで青白く光る）、自然金（砂金）、ボーキサイト（電力が要る終盤素材）、クロム鉄鉱、チタン鉄鉱（砂鉄・白顔料）
- 「探し方」の個性：磁石に反応／UVで光る／叩くと臭う

## 4. 試作で確かめること
- 赤鉄鉱・磁鉄鉱：副産物で「今は磁鉄鉱が欲しい」が起きるか
- 孔雀石・黄銅鉱：工程差（序盤向け vs 量産向け）で差別化できるか
- 錫石：ふるい採取と青銅の配合比いじりが楽しいか
