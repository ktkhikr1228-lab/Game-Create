# 企画の正本（design.md）

> オーナーが更新する。AIは直接書き換えず、Issueで提案する（オーナーの指示があるときを除く）。
> 状態：`確定` / `案` / `未決`

## 1. コンセプト
- タイル式の2D採掘・クラフト（Terraria風）　`確定`
- 実在の鉱物を採掘 → 精錬で金属を取り出す → 配合を変えて合金を作る　`確定`
- 序盤〜中盤は実在の素材が主役。オリジナル鉱石は、進むほど比率が上がる　`確定`
- 古いティアの素材が後半で使われなくなるのはOK（ティアの乗り換えで進行感を出す）　`確定`

## 2. 装備
- **基本装備は、精錬した単体金属で作れる**。持ち手は木でも金属などでもよい。合金・木の種類・宝石は、性能や使い心地を変えるもの　`確定`
- 武器・道具は全部パーツ式。どの武器も「主パーツ・持ち手・核」の3役割にそろえる　`確定`

| 武器 | 主パーツ | 持ち手 | 核 |
|---|---|---|---|
| ツルハシ | 先端（金属・合金） | 柄（木・金属など） | 宝石 |
| 剣 | 刃（金属・合金） | 柄（木・金属など） | 柄頭の宝石 |
| 杖 | 金具・台座（金属）＝マナ効率 | 杖身（木・金属など）＝詠唱速度 | 杖頭の宝石＝魔法の種類 |
| 弓 | 弓身（木）＝威力 | 握り | 矢じり（鉱物）＝状態異常 |
| 銃 | 銃身（金属・合金） | 銃床（木・金属など） | 弾（鉱物） |

- 上の割り当て　`案`
- パーツは1つの武器につき最大3つ　`案`
- クラス固定なし（モンハン型）。誰でもどの武器も使える。防具のスキルで役割が寄る　`確定`
- 防具は4部位（頭・胴・腕・脚）＋アクセサリー　`確定`
  - アクセサリー枠は3〜4個　`案`
  - シリーズボーナスは2部位／4部位で発動。2＋2で2シリーズの両取りもできる　`案`
  - 腕は「道具の扱い」系のスキル（振りの速さ、弾かれにくさ、溜め）　`案`
  - 防具の素材（合金）がスキルの元になる。名前つき合金の区画ならフル、外れたら弱いスキルだけ　`案`
  - スキルは最初15〜20個程度に抑える　`案`
- 宝石は、杖の核と、防具・アクセサリーのスロットの両方に使う　`案`
- アクセサリーは鉱物と宝石からクラフトする（ランダムドロップにしない）　`案`

## 3. 合金
- 配合はある程度刻む。自由すぎない　`確定`
- 操作は「金属を選ぶ → 配合を選ぶ → 作る量を選ぶ」　`案`（GPTとの壁打ちで出た案。旧案のスロット式・ナゲット式は保留）
- 少量の添加（炭素・マンガン・バナジウム・融剤など）は別枠で入れる　`案`
- 配合が合金の種類と性能の方向を決める　`案`
- 1つの装備に注ぎ込む素材が多いほど品質が上がるが、そのぶんコストが増える　`案`（一旦この方向）
  - 効果は逓減する（つぎ込むほど伸びが鈍る）
  - 品質の上限は炉のティアで決まる
  - ティアが上がると古い装備は使われなくなるので、古いティアにつぎ込みすぎると損になる
- 名前つき合金は「配合の中の当たり区画」。試作3〜4種、最初の版で10〜15種が目安　`案`
- 多ければ強い、にしない。スイートスポットと谷を置く（青銅の錫比率など）　`案`

### 炉
- 炉にはティアがある。ティア＝出せる温度で、扱える金属と品質の上限が決まる　`案`
  - 例：序盤の炉は銅・錫、上の炉で鉄、さらに上で特殊鋼・オリジナル鉱石
- 後半は、急冷槽・焼き戻し炉のような付属設備で、合金の得意な特性を伸ばせる。そのかわり別の特性が下がる（例：硬さに振ると脆くなる）　`案`

## 4. 鉱物の差別化方針
- 精錬後の主金属は共通（赤鉄鉱からも磁鉄鉱からも同じ「鉄」）　`確定`
- 個性は **副産物・工程・探し方** に持たせる　`案`
- 副産物を合金の「添加材」として効かせる　`案`
- 主金属は由来を問わず1スタックに統合し、副産物だけ別スタック　`案`

### 避けたいこと（他ゲームからの教訓）
- 微差の数値だけで横並びにすると実質リスキンになる（Terrariaの銅/錫）
- 産出量に見合う消費先がないとゴミ鉱石扱いになる（Minecraftの銅）
- 配合が単純な足し算だと最適解が1つに収束する

### 鉱物候補（試案）
`【現】` 現実の性質　/　`【ゲ】` ゲーム独自の効果

| 鉱物 | 主金属 | 【現】 | 【ゲ】案 | 欲しくなる場面 |
|---|---|---|---|---|
| 赤鉄鉱 | 鉄 | 条痕が赤い、赤オーカー、研磨剤 | 副産物：研磨粉 → 宝石の品質アップ | 良い原石を拾った直後 |
| 磁鉄鉱 | 鉄 | Fe約72%、磁性、チタン磁鉄鉱はバナジウム源 | 歩留まり◎、磁性粉、まれにV | 新バイオーム前、V鋼を作りたいとき |
| 褐鉄鉱（沼鉄鉱） | 鉄 | 沼で再生、リンが多く脆い鉄になりやすい | 沼でリスポーン、低歩留まり | 序盤、掘り尽くしたあと |
| 菱鉄鉱 | 鉄 | 焙焼が必要、Mnを含み製鋼向き | 副産物Mn（鋼の添加材） | 鋼に進むタイミング |
| 黄鉄鉱 | （鉄にならない） | 打つと火花、硫黄が多い | 着火具・硫黄（火薬）、まれに金 | 松明・火薬が要るとき |
| 孔雀石 | 銅 | 還元しやすい、緑顔料 | 低ランク炉でOK、緑染料 | 序盤 |
| 黄銅鉱 | 銅 | Cu約35%、脱硫が必要 | 量は多いが設備が要る | 量産したいとき |
| 自然銅 | 銅 | 精錬せず叩いて加工できる | 炉なしで使える、少量 | 出先で道具が壊れたとき |
| 錫石 | 錫 | 比重約7、川の砂錫 | 川底で採取、青銅の鍵 | 青銅を作りたいとき |
| 方鉛鉱 | 鉛 | 含銀方鉛鉱は銀の主要源、重い | 鉛（弾）＋銀（宝石の台座） | 銃・魔力装備を作るとき |
| 蛍石 | — | 製錬の融剤 | 精錬の歩留まり・品質アップ | 大量精錬の前 |

増やすときの候補：閃亜鉛鉱、辰砂、輝安鉱、硫砒鉄鉱、灰重石、自然金、ボーキサイト、クロム鉄鉱、チタン鉄鉱、硝石

## 5. 木
- 交配はしない。実在の木の種類で差をつける（交配は将来の拡張候補）　`確定`
- 育てる楽しさの優先度は低め　`確定`
- 柄の特性軸は「速さ」より「できること・場面の向き不向き」で分ける（リーチ、衝撃吸収、溜め、耐水、軽さ）　`案`
- 坑木（崩落対策の支柱）にも使う。木の種類で支えられる強さが違う　`案`

| 木 | 【現】 | 【ゲ】案 |
|---|---|---|
| ヒッコリー | 粘りがあり衝撃に強い。斧・ハンマーの柄の定番 | 衝撃吸収 |
| トネリコ | 弾力がある。道具の柄やバット | しなり→溜め |
| カシ | 硬くて重く丈夫 | 重い一撃、壊れにくい |
| チーク | 油分が多く水や腐りに強い | 耐水 |
| リグナムバイタ | 非常に密度が高く水に沈む | 最重量級 |
| 竹 | 軽くてしなる | 軽い、長い柄（リーチ） |
| イチイ | ロングボウの定番材 | 弓身 |

## 6. 魔法・状態異常
- 魔法はTerraria型。マナはプレイヤー側のステータスで、杖などで消費する。宝石自体は減らない　`確定`
- 弱点・耐性の相性表（属性）は作らない　`確定`
- 戦い方の違いは状態異常で出す。役割が被らないようにする　`確定`
- 同じ状態異常を、クラスごとに別ルートで付けられる（近接＝添加材・塗布、遠隔＝矢じり・弾、魔法＝宝石）　`案`
- 宝石の個性はマナ回復の補助として残す（例：掘ると回復、熱源の近くで回復が速い）　`案`
- 宝石は「母体の鉱物＝器、微量元素＝付く効果」で作る　`案`

| 状態異常 | 役割 | 元になる素材 |
|---|---|---|
| 燃焼 | 継続ダメージ、燃え広がる | ルビー、黄鉄鉱 |
| 凍結 | 移動が遅くなる、重なると止まる | サファイア |
| 毒 | 継続ダメージ、回復量が減る | 辰砂、ヒ素 |
| 脆化 | 受けるダメージが増える | 蛍石 |
| 帯電 | 短時間止める、連鎖する | 水晶、トルマリン |
| 磁化 | 敵を引き寄せる | 磁鉄鉱 |
| 露見 | 透明な敵が見える、クリティカル率アップ | 灰重石 |
| 重圧 | 飛んでる敵を落とす | 方鉛鉱 |

- 上の表　`案`。試作は4つ（燃焼・凍結・脆化・帯電）、最初の版で6〜8つ　`案`

## 7. 進行
- 銃は中盤手前で解禁　`確定`
- 銃の解禁の鍵は硝石（硫黄と木炭は序盤から手に入る）。最初の銃身は青銅　`案`
- 弓と銃は住み分ける（銃＝一発が重い・運用コスト高、弓＝連射・状態異常向き）　`案`

### 進行のイメージ　`案`
1. 序盤：自然銅・孔雀石 → 銅 → 錫石 → 青銅
2. 中盤手前：硝石 → 火薬・銃
3. 中盤：鉄・鋼・特殊鋼（マンガン鋼・バナジウム鋼・ステンレス）
4. 終盤：オリジナル鉱石が主役、宝石の本格運用

## 8. 世界・地形
- 地形はタイル式　`確定`
- 砂・砂利・瓦礫などの緩い素材だけ細かいセルで崩れる。支えを失った岩盤は塊ごと落ちて瓦礫に砕ける（簡略版）　`案`
- 「地域（草原・火山など）」「地層（地下で出会う層）」「施設（水車小屋など）」を分けて扱う　`案`
- 深くなるほど崩れやすく、オリジナル鉱石の比率が上がる　`案`

### 崩落
- 崩落は怖いもの寄りにする　`確定`
- 巻き込まれたらダメージを受ける（埋まる・即死はなし）　`確定`
- 崩れる前に予兆を出す（砂ぼこり、ひび、きしむ音）　`案`
- ダメージは崩れた量・落下の高さ・岩の重さで変わる。頭の防具の「落石軽減」で減らせる　`案`
- 崩落の原因は基本的にプレイヤーの行動。自然の崩落は深層の特別な場所だけ　`案`
- 崩れやすい地層は見た目で分かるようにする。坑木で支えられる　`案`

## 9. オリジナル鉱石
- 序盤は1〜2種、中盤3〜4種、終盤が主役　`案`
- 序盤のものは「見つかるけど、まだ使いこなせない」。使えても宝石の核や魔法の入口程度　`案`
- 実在の鉱物と同じ「性質の言葉」（光る、重さ、熱、磁性など）で作る　`案`
- 候補（名前は仮）：灯晶石（暗所で光る、魔力の入口）、浮遊鉱（掘ると昇っていく）、吸魔鉱（近くでマナを吸う）、冷鉱（熱を吸うので序盤の炉では溶かせない）、共鳴晶洞（GPTとの壁打ちで出た案）　`案`

## 10. クラフト・レシピ
- 普通のアイテム（ブロック・家具・薬・弾・坑木）はTerraria式：作業台の近くで一覧から作る　`案`
- 合金・装備の組み立て・宝石の研磨は、それぞれ専用の画面　`案`
- 作業台：炉（精錬）、るつぼ（合金）、金床（パーツ加工）、木工台、砥石（研磨）　`案`
- レシピは「未発見（？？？）→ ヒント → 解放」の3段階　`確定`
  - 基本的なアイテムは素材を拾ったらすぐ解放　`案`
  - 合金は、狙った区画に当てたら図鑑に登録される　`案`
- ヒントは図鑑と、世界の中で見つかる書物（昔の鍛冶師の手記など）で出す。鑑定の仕組みは作らない　`確定`
- 図鑑の項目は「観察／ありか／用途」の3つ。観察は現実と矛盾しないように書き、用途はゲーム内の話として書く　`案`
- ゲーム内の文章のルールは `AGENTS.md` を参照　`確定`

## 11. 試作で確かめること
- **銅の剣を作ったプレイヤーが、どこで初めて青銅の剣を作りたくなるか**（最初の敵、錫を探しに行く場所、合金の操作をひとつの場面で）
  - 叩き台：序盤の洞窟に甲殻の硬い敵 → 銅の剣だと弾かれる → 近くの川底で錫石 → 初めての合金 → 青銅の剣で甲殻を割れる
- 赤鉄鉱・磁鉄鉱：副産物で「今は磁鉄鉱が欲しい」が起きるか
- 孔雀石・黄銅鉱：工程差（序盤向け vs 量産向け）で差別化できるか
- 錫石：川での採取と、青銅の配合いじりが楽しいか
- 柄2本の比較：柄A「長い・重い」と柄B「短い・衝撃吸収」が、それぞれ勝つ場面を作って、プレイヤーが自分から持ち替えるか
