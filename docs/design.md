## 1. コンセプト
- タイル式の2D採掘・クラフト（Terraria風）　`確定`
- 実在の鉱物を採掘 → 精錬で金属を取り出す → 配合を変えて合金を作る　`確定`
- 序盤〜中盤は実在の素材が主役。オリジナル鉱石は、進むほど比率が上がる　`確定`
- 古いティアの素材が後半で使われなくなるのはOK（ティアの乗り換えで進行感を出す）　`確定`
- 根底の方針は「自由気ままに」。進み方・寄り道・町に戻るかどうかをプレイヤーが選べることを優先する　`確定`

## 1.5 世界観・目的
- メインの目的は置かない。掘る・作る・寄り道するのを好きに楽しむゲームにする（§1「自由気ままに」）　`確定`（2026-11-26）
  - 町の再興と「深くなるほど世界が変わっていく謎」は、やってもやらなくてもいい要素として残す
  - 依頼（サブクエスト）も、好きなときに受けられる軽い頼みごと程度。受けなくても進める
- やってもやらなくてもいい要素（町の施設を全部直す、地下の源にたどり着く、依頼をこなす など）は実績として扱う　`案`（2026-11-26）
  - 実績は目印で、取らなくても損をしない。報酬を付けるなら見た目や図鑑の記録程度
- 骨格　`案`
  - 昔栄えた鉱山町。深い坑道で崩落が続き、見たことのない石が出るようになって、人がいなくなった
  - プレイヤーは町にやってきて、好きに深く掘っていく。町の施設は直すと便利になるが、直さなくても進める
  - 施設を直すと機能が解禁される（かまど → 合金炉 → 水車工房 → 特殊設備）。施設が直ると職人が戻り、研磨や本などが解禁される
  - 職人は自分の専門の仕事だけをする。何でも教えてくれる案内役にはしない
  - 深さで謎が見えてくる：浅い＝普通の鉱山、たまに灯晶石／中＝昔の鉱夫の手記／深い＝オリジナル鉱石だらけで崩落も増える／最深部＝地下の源（いちばん奥の区切り。行くかどうかは自由）
- 物語の濃さ（ほぼ説明なしか、手記や会話で読ませるか）　`未決`

### 世界のイベント
- 隕石は入れる　`確定`
  - 【現】精錬の技術より前から、隕石の鉄（隕鉄）は使われていた
  - 【ゲ】序盤に落ちてくると、まだ精錬できない特別な鉄（ニッケル入り）が少し手に入る。ティアを先取りするご褒美のイベント　`案`
- 噴火は火山の地域の中だけで起きる　`確定`
  - 【現】火山の噴気口の周りには硫黄が溜まる
  - 【ゲ】溶岩が流れ出して危ないが、収まると新しい鉱石や硫黄の鉱床が露出する。拠点には届かないようにする　`案`
- 季節は後回し　`確定`
  - 入れるなら川の水位など採掘に効く形にする（渇水期は川底の錫石が採りやすい、増水期は水車がよく回る）　`案`

## 2. 装備
- **基本装備は、精錬した単体金属で作れる**。持ち手は木でも金属などでもよい。合金・木の種類・宝石は、性能や使い心地を変えるもの　`確定`
- 武器・道具は全部パーツ式。どの武器も「主パーツ・持ち手・核」の3役割にそろえる　`確定`

| 武器 | 主パーツ | 持ち手 | 核 |
|---|---|---|---|
| ツルハシ | 先端（金属・合金） | 柄（木・金属など） | 宝石 |
| 剣 | 刃（金属・合金） | 柄（木・金属など） | 柄頭の宝石 |
| 杖 | 金具・台座（金属）＝マナ効率 | 杖身（木・金属など）＝詠唱速度 | 杖頭の宝石＝魔法の種類 |
| 弓 | 弓身（木）＝威力 | 握り | 矢じり（鉱物）＝状態異常 |
| 銃 | 銃身（金属・合金） | 銃床（木・金属など） | 弾（鉱物） |

- 上の割り当て　`案`
- パーツは1つの武器につき最大3つ　`案`
- クラス固定なし（モンハン型）。誰でもどの武器も使える。防具のスキルで役割が寄る　`確定`
- 防具は4部位（頭・胴・腕・脚）＋アクセサリー　`確定`
  - アクセサリー枠は3〜4個　`案`
  - シリーズボーナスは2部位／4部位で発動。2＋2で2シリーズの両取りもできる　`案`
  - 腕は「道具の扱い」系のスキル（振りの速さ、弾かれにくさ、溜め）　`案`
  - 防具の素材（合金）がスキルの元になる。名前つき合金の区画ならフル、外れたら弱いスキルだけ　`案`
  - スキルは最初15〜20個程度に抑える　`案`
- 宝石は、杖の核と、防具・アクセサリーのスロットの両方に使う　`案`
- アクセサリーは鉱物と宝石からクラフトする（ランダムドロップにしない）　`案`

## 3. 合金
- 配合はある程度刻む。自由すぎない　`確定`
- 操作は「金属を選ぶ → 配合を選ぶ → 量を選ぶ」の3手。画面を切り替えず、るつぼの1画面で行う　`確定`（#14）
  - 量は2つの欄に分ける：**1個あたりの投入量（＝品質）** と **作る個数**
  - 品質は段で選ぶ。1段＝合計10本を配合どおりに割り振る（Cu90:Sn10なら1段で銅9・錫1、2段で銅18・錫2）。段に「並・良」のような名前は付けず、1個あたりに実際に使う量と、炉のティアによる上限を見せる
  - 1段10本が序盤に重い場合は、刻みではなく精錬で出る金属の数のほうで調整する
  - 材料は「必要／利用可能」で表示する（例：`銅：必要18／利用可能40`）。利用可能＝手持ち＋工房の箱にある精錬済みの金属（るつぼの中の溶けた金属は管理しない）
  - 「あと何回作れるか」は、個数欄の「最大○個」として出す
- 初めての合金だけ配合を Cu90:Sn10 に固定する（ゲーム全体で最初の1回だけ）。2回目以降は動かせる。動かせるようになることは、初回の時点で図鑑のヒントで知らせる　`確定`
- 銅・錫の配合は10%刻み。名前つき合金の区画は目盛りに合わせて置く（区画の中に、選べる比率が最低1つある）　`確定`
  - 銅・錫以外の刻み幅は未定。合金系ごとにデータで変えられるようにしておく
- 配合の操作は＋−ボタンが主、目盛りのタップが補助。ドラッグは主にしない（指で数値が隠れる、画面端の「戻る」ジェスチャーと誤爆する）　`確定`
- 作る前は性能の方向だけを予告する　`確定`
  - 比較の基準は、選んだ2つの金属のうち割合が多い方の単体金属（50:50なら先に選んだ金属）。例：「純銅より ↑硬さ ↓熱伝導」
  - 矢印は値の増減だけを表し、良し悪しの色は付けない（熱伝導のように、武器と防具で得と損が逆になる軸があるため）
  - 変化の大きい2〜3軸と特性タグを出し、残りの軸は開けば見られる
  - 作ったあとに、実際の値と合金名を図鑑に登録する。記録には配合と品質の段を併記する
- スマホでは、比率バー・予告・消費量の3つが同時に見えていることを必須にする。それ以外はスクロールしてよい。画面下に固定するのは「作る」ボタンと合計消費の要約だけ　`確定`
- 試作の主金属は2種まで（比率バー1本で表せる範囲）　`確定`
- 少量の添加（炭素・マンガン・バナジウム・融剤など）は別枠で入れる　`案`。最初の銅・錫の試作では扱わない
- 配合が合金の種類と性能の方向を決める　`案`
- 1つの装備に注ぎ込む素材が多いほど品質が上がるが、そのぶんコストが増える　`案`（一旦この方向）
  - 効果は逓減する（つぎ込むほど伸びが鈍る）
  - 品質の上限は炉のティアで決まる
  - 品質で伸びるのは装備の基礎性能（攻撃・防御・耐久）だけ。6軸と特性は配合で決まり、品質では変わらない　`確定`（#38）
  - ティアが上がると古い装備は使われなくなるので、古いティアにつぎ込みすぎると損になる
- 名前つき合金は「配合の中の当たり区画」。試作3〜4種、最初の版で10〜15種が目安　`案`
- 多ければ強い、にしない。スイートスポットと谷を置く（青銅の錫比率など）　`案`

### 性能の軸と特性
- 軸6つ＋特性いくつか。特性はスキルや武器の効果になる　`確定`（一旦この方向）
- 重さの軸は入れない　`確定`
- 数値を無理に釣り合わせない。「ここは突き抜けて強い、ここはまるでダメ」という尖った性能でよい　`確定`
- 軸の値は1〜100で表す。100は「普通に作れる上限の目安」で、本当の上限ではない　`確定`（2026-11-26）
  - 熱処理を重ねる・添加材を組み合わせる・性質の違う金属を重ねて鍛える、など手間をかければ現実の合金でも100を超えられる。1上げるごとに手間が増え（逓減）、別の軸が下がるトレードオフも付ける　`案`
  - 100超えはエンドコンテンツ。普通に進む道の壁は100を超えなくても越えられるようにする　`確定`
  - オリジナル鉱石は数値の高さではなく、現実の金属にない特性で勝負する　`案`
  - 品質（つぎ込む量）では軸は伸びない（上の決まりのまま）
  - 各素材の値のたたき台は Claude Doc「金属の6軸の値（たたき台）」

**軸：全部の金属に値がある（バーで見せる）**　`案`

| 軸 | 【現】の根拠 | 【ゲ】何に効くか |
|---|---|---|
| 硬さ | 金属の硬さ | 掘れる岩の硬さ、硬い殻に弾かれないか、防御 |
| 粘り | 割れにくさ（靭性） | 耐久、強い衝撃で壊れないか |
| 耐熱 | 融点 | 溶岩・火山・燃焼への強さ |
| 耐食 | 錆びにくさ | 水中・毒・沼での劣化 |
| 魔力伝導 | 電気の通しやすさ（銀・銅はよく通し、鉄やステンレスは通しにくい） | 杖の金具や台座、マナ効率 |
| 熱伝導 | 銅は熱をよく伝える | 武器なら燃焼・凍結が伝わりやすい。防具だと熱が伝わって不利になる |

- トレードオフ：硬さ↔粘り（焼き入れで硬いが脆い）、魔力伝導↔硬さ（よく電気を通す銀や銅は柔らかい）

**特性：一部の金属だけが持つ（タグで見せる）**　`案`

| 特性 | 持つ金属の例 | スキル・効果の例 |
|---|---|---|
| 磁性 | 鉄、鋼、ニッケル | 引き寄せ、磁化、磁性のある敵への効き |
| 響き | 錫の多い青銅（鐘の青銅） | 共鳴晶洞での反応、音で敵を怯ませる |
| 毒性 | 鉛、ヒ素青銅 | 攻撃に毒が付くが、使い手も少し毒を受ける |
| 反射 | 銀 | 光の魔法を跳ね返す |
| 鋭さ | よく鍛えた鋼 | 切る攻撃の強さ、クリティカル |
| 加工しやすさ | 金、銅 | 品質を上げやすい、修理しやすい |

- 特性は変質と同じくデータで足していける
- 防具に使えば防具のスキル、武器に使えば武器の効果になる

### 炉
- 炉にはティアがある。ティア＝出せる温度で、扱える金属と品質の上限が決まる　`案`
  - 例：序盤の炉は銅・錫、上の炉で鉄、さらに上で特殊鋼・オリジナル鉱石
- 後半は、急冷槽・焼き戻し炉のような付属設備で、合金の得意な特性を伸ばせる。そのかわり別の特性が下がる（例：硬さに振ると脆くなる）　`案`

## 4. 鉱物の差別化方針
- 精錬後の主金属は共通（赤鉄鉱からも磁鉄鉱からも同じ「鉄」）　`確定`
- 個性は **副産物・工程・探し方** に持たせる　`案`
- 副産物を合金の「添加材」として効かせる　`案`
- 主金属は由来を問わず1スタックに統合し、副産物だけ別スタック　`案`

### 避けたいこと（他ゲームからの教訓）
- 微差の数値だけで横並びにすると実質リスキンになる（Terrariaの銅/錫）
- 産出量に見合う消費先がないとゴミ鉱石扱いになる（Minecraftの銅）
- 配合が単純な足し算だと最適解が1つに収束する

## 5. 木
- 交配はしない。実在の木の種類で差をつける（交配は将来の拡張候補）　`確定`
- 育てる楽しさの優先度は低め　`確定`

## 6. 魔法・状態異常
- 魔法はTerraria型。マナはプレイヤー側のステータスで、杖などで消費する。宝石自体は減らない　`確定`
- 弱点・耐性の相性表（属性）は作らない　`確定`
- 戦い方の違いは状態異常で出す。役割が被らないようにする　`確定`
- 同じ状態異常を、クラスごとに別ルートで付けられる（近接＝添加材・塗布、遠隔＝矢じり・弾、魔法＝宝石）　`案`
- 宝石の個性はマナ回復の補助として残す（例：掘ると回復、熱源の近くで回復が速い）　`案`
- 宝石は「母体の鉱物＝器、微量元素＝付く効果」で作る　`案`

| 状態異常 | 役割 | 元になる素材 |
|---|---|---|
| 燃焼 | 継続ダメージ、燃え広がる | ルビー、黄鉄鉱 |
| 凍結 | 移動が遅くなる、重なると止まる | サファイア |
| 毒 | 継続ダメージ、回復量が減る | 辰砂、ヒ素 |
| 脆化 | 受けるダメージが増える | 蛍石 |
| 帯電 | 短時間止める、連鎖する | 水晶、トルマリン |
| 磁化 | 敵を引き寄せる | 磁鉄鉱 |
| 露見 | 透明な敵が見える、クリティカル率アップ | 灰重石 |
| 重圧 | 飛んでる敵を落とす | 方鉛鉱 |

- 上の表　`案`。試作は4つ（燃焼・凍結・脆化・帯電）、最初の版で6〜8つ　`案`

### 魔法の媒体　`案`
- 媒体は3つ。それぞれ使う素材の系統を分ける
  - **杖**：宝石で撃つ。基本の魔法
  - **本**：鉱物から作ったインクで魔導書に書く。インクの色で効果が決まる。複数の効果の組み合わせや、場に作用する魔法（天井を固める、鉱脈を浮かび上がらせる、など）を担当する
    - 【現】孔雀石は緑、藍銅鉱は青、辰砂は朱、赤鉄鉱は赤の顔料として使われてきた
    - 新しい書き方は、世界で見つかる書物のページから覚える
  - **召喚**：鉱物や合金で彫った像を媒体に、ゴーレムのようなものを呼ぶ。像の素材が召喚獣の性能になる（重い素材は設置型、軽い素材は追従型、など）
    - 召喚獣に掘らせるかどうかは、自動採掘の議題で一緒に考える
- 試作は杖だけ。本と召喚は中盤以降に解禁する

### 杖の魔法の決まり方　`案`
- 宝石の種類 → 効果（状態異常）
- カット → 撃ち方（例：丸＝直進、多面＝ばらまき、尖り＝貫通、平たい＝設置）
- 品質 → 強さ
  - 色の濃さ → 状態異常の強さ
  - 透明度（内包物の少なさ）→ マナ効率、貫通
  - 大きさ → 威力、範囲
  - カットの出来 → 精度、弾速
  - まれに内包物が当たりの特性になる
  - 【現】宝石の品質は色・透明度・カット・大きさで評価される
- 最大マナは、灯晶石をマナの器にして増やす

### 魔法の個性の柱　`案`
数字（威力・消費）だけで差をつけない（Terrariaの宝石の杖が色違いに近いのを反面教師にする）。柱は次の3本。
- **地形・環境に作用する**：燃焼は木や硫黄に燃え広がる、凍結は水や溶岩を固めて足場にする、帯電は水に流れる、衝撃系は岩を砕けるが崩落の予兆を出す
- **コスト・リスクの形を変える**：溜め、反動、連射での過熱、自分も巻き込まれる、崩落を誘う
- **条件で強さが変わる**：昼と夜、熱源の近く、深さ、水中など、宝石ごとに得意な状況がある
- 撃ち方・操作感（押しっぱなし、溜め、設置して起爆、誘導）やコンボ（凍結→砕く、濡れ＋帯電、燃焼＋硫黄で爆発）は、柱を支える要素として使う

## 7.5 動力・自動化
- 自動化は入れる　`確定`

**地域：完全に架空（遠く・高く）**

- 灰の平原・光る霧は、地下の源の力が地上まで漏れ出している、とつなげられる

**地域の数とくり返し**　`案`
- 世界の大きさに合わせて、同じ種類の地域をくり返す（「町の近く → 現実寄り → 大げさ → 架空」の順は守る）

## 10.5 インベントリと保管
- 持ち物の容量は、最初はきつめ。あとから量を強化できる　`確定`
- 収集用の鉱物（標本）は、自分で持ち帰る（自動で町に送らない）　`確定`

**入れ物を分ける**　`案`
- 鉱石袋：精錬に使う鉱石だけを入れる。何種類入れても普通のスロットを使わない。容量はアップグレードで増える
- 標本ケース：収集用の鉱物だけを入れる。仕切りの数が容量で、アップグレードで増える。いっぱいのときに珍しい標本を見つけたら、どれを置いていくか悩む
- 普通のスロット：道具・武器・消耗品・変質したアイテム

**重ねるルール**　`案`
- 主金属は由来に関係なく1つにまとめる
- 鉱石は種類ごと。変質したアイテムは変質ごとに別のスタック
- 装備は品質が1個ずつ違うので重ならない

**容量を広げる手段**　`案`
- 鉱石袋・標本ケースを素材のティアに合わせて作り直す
- 町の再興と連動して、施設や職人が戻るとスロットが増える
- 運ぶ仕組みで解決する：坑道の中継の箱に入れて、トロッコや巻き上げ機で町へ送る

**きつめでもストレスにしない工夫**　`案`
- 持ちきれなかったアイテムは消えずにその場に残る
- 帰還の巻物で戻るときは、持っている分は全部持ち帰れる

**町での保管**　`案`
- 近くの箱に同じ種類をまとめて入れるボタン
- 作業台の近くの箱の素材を、インベントリに出さずにクラフトに使える
- 鉱石袋の中身を工房にまとめて預けて精錬に回す
